# JARVIS — Cross-Device AI Voice Assistant & Automation Ecosystem

**JARVIS (`JarvisApp`)** is an open-source, local-first AI voice assistant and desktop automation hub built for Windows, designed to work seamlessly alongside its Android companion app ([`jarvis-android`](https://github.com/editorshamim4108-cmd/jarvis-android)). It bridges voice interaction, autonomous desktop control, and cross-device synchronization into a lightweight, customizable workflow.

## Key Features

- **Bilingual Voice Interface (English & Bengali):** Supports natural speech-to-text recognition and expressive neural text-to-speech responses across both English and Bengali.
- **Autonomous Desktop Automation:** Hands-free application launching, system health monitoring, local drive file/folder indexing, native directory archiving, and multi-step action chaining.
- **Action-Verify Execution Loop:** Uses screen capture verification and automated UI controls to execute and validate desktop tasks reliably.
- **Cross-Device Sync (PC & Android):** Real-time command routing, remote power management, and file-sharing workflows between Windows PC and Android devices.
- **Customizable & Modular:** Supports dynamic behavioral rules (`jarvis_rules.json`), multi-model fallback routing, and automated build scripts.
